# Installed skills — Kepler Drift (Unity 6 + C#)

Three layers:
1. **Project skill** `kepler-drift-unity`: read before any Unity work (rules, ladder, traps).
2. **Unity official plugin** (Unity-Technologies/unity-agent-plugin, Sept 2026, ~45 skills + CLI):
   installed by `tool/cloud_setup.sh`; on the PC `/plugin install unity@unity-agent-plugin`.
   Not copied into the repo (Unity Companion License). First stops: `unity-cli`,
   `urp-postprocessing`, `create-2d-physics`, `ui-uitk`, `optimize-audio`, `localization`,
   `implement-in-app-purchases`.
3. **Selected copies from sandikapp** (for judgment, not syntax): `ui-ux-pro-max`,
   `emil-design-eng`, `animate`, `apple-design` (feel/timing; CSS/React syntax is not taken,
   the C#/URP equivalent is), `code-reviewer`, `debugging-wizard`, `the-fool`,
   `architecture-designer`, `test-master` (strategy; NUnit/Unity Test Framework for C#), `skill-creator`.

Rule: when a skill conflicts with this repo's `CLAUDE.md`, CLAUDE.md wins; note the conflict in
the summary. Flutter/Supabase/SQL skills are deliberately absent (no Flutter shell, no server here).
